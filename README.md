# AUCC — ระบบจองและจัดการเครื่องคอมพิวเตอร์

ระบบสำหรับห้องคอมพิวเตอร์ ผู้ใช้จองและเข้าใช้เครื่องผ่านหน้าเว็บ ผู้ดูแลดูสถานะ ควบคุมเครื่อง และดูประวัติการใช้งานจากเครื่องแม่ได้

**รุ่นปัจจุบัน: 1.0.0** · [ดาวน์โหลด Server Setup](https://github.com/chaiyapatrx/Project/releases/download/v1.0.0/AUCCServerSetup-1.0.0.exe) · [Release และ SHA-256](https://github.com/chaiyapatrx/Project/releases/tag/v1.0.0)

## แต่ละส่วนทำอะไร

| ส่วน | หน้าที่ | โฟลเดอร์ |
|---|---|---|
| หน้าเว็บ (React) | เข้าสู่ระบบ จองเครื่อง ดูสถานะและรายงานตามสิทธิ์ | `frontend` |
| Server (Go) | ตรวจสิทธิ์ จัดการการจอง/เวลาใช้งาน และส่งคำสั่งให้เครื่องลูก | `backend-go` |
| ฐานข้อมูล (MariaDB) | เก็บบัญชี สถานี การจอง การตั้งค่า และประวัติ; migration จัดโครงสร้างฐานข้อมูล | `migrations` |
| Agent บน Windows | เชื่อมเครื่องแม่ แสดงหน้าล็อก รับรหัสเข้าใช้ และรายงานสถานะเครื่อง | `client-go` |
| Updater | เปลี่ยนรุ่น Agent เมื่อผู้ดูแลปล่อยอัปเดต และคืนรุ่นเดิมหากรุ่นใหม่เปิดไม่ผ่าน | `client-go/updater` |
| ตัวติดตั้ง | เตรียม Server และสร้างชุด Client ที่มีค่าการเชื่อมต่อพร้อมใช้ | `installer`, `scripts` |

```text
หน้าเว็บ ── HTTPS / สถานะสด ── เครื่องแม่ ── ฐานข้อมูล
                                  │
                           WSS / คำสั่งเครื่อง
                                  │
                           Agent บนเครื่องลูก
```

**เครื่องแม่** เปิดเว็บและจัดการข้อมูลกลาง ส่วน **เครื่องลูก** ติดตั้ง Agent แล้วเชื่อมกลับมายังเครื่องแม่ ทุกเครื่องใช้ Server เดียวกัน

## วิธีใช้งาน

1. เครื่องลูกเชื่อมต่อและแสดงหน้าล็อก ผู้ดูแลเห็นสถานะบนเว็บ
2. ผู้ใช้จองเครื่องว่างบนเว็บ ได้ **Access Code 6 หลัก** แล้วกรอกที่เครื่องนั้นเพื่อเข้าใช้ การจองเริ่มทันที ไม่ใช่จองวันเวลาล่วงหน้า
3. ถ้าเครื่องว่างและไม่มีการจอง ผู้ใช้ล็อกอินด้วยบัญชี AUCC ที่เครื่องได้โดยตรง (walk-in)
4. ระบบบันทึกประวัติและนับเวลา เมื่อหมดเวลา ยกเลิก หรือสั่ง `LOGOUT` จะจบการใช้งานและกลับหน้าล็อก หากขาดการเชื่อมต่อ Agent จะล็อกหน้าจอ

| สิทธิ์ | ใช้งานได้ |
|---|---|
| Admin | จัดการบัญชี/สถานี ตั้งค่าระบบ ควบคุมเครื่อง และอัปโหลดรุ่น Agent |
| Staff | ดูสถานี/การจอง/ประวัติ ควบคุมเครื่อง และปล่อยหรือพักรุ่น Agent ที่อัปโหลดแล้ว |
| Executive | ดูสถิติและรายงาน |
| Student | จอง ดู ยกเลิก และต่อเวลาการจองของตนตามเงื่อนไข |

## ติดตั้งแบบง่าย

เตรียม Windows 10/11 แบบ x64 เครื่องแม่ต้องใช้สิทธิ์ผู้ดูแลตอนติดตั้ง เครื่องลูกต้องเข้าถึงเครื่องแม่ผ่านเครือข่ายและแปลงชื่อเครื่องแม่เป็น IP ได้ ไม่ต้องติดตั้ง Go, Node.js, Python หรือ XAMPP บนเครื่องใช้งาน ตัวติดตั้งรวม runtime แล้วและติดตั้งแบบ offline ได้

### 1. ติดตั้งเครื่องแม่ (Server)

1. ดาวน์โหลด [AUCCServerSetup-1.0.0.exe](https://github.com/chaiyapatrx/Project/releases/download/v1.0.0/AUCCServerSetup-1.0.0.exe)
2. เปิดไฟล์ อนุญาต UAC แล้วกดติดตั้ง
3. Setup เตรียมฐานข้อมูล บัญชี Admin พร้อมรหัสสุ่ม HTTPS กฎ firewall และการเริ่ม Server อัตโนมัติหลังเปิดเครื่อง
4. หน้าสุดท้ายเปิดข้อมูลล็อกอินและเว็บ เข้าด้วยบัญชีที่สร้างให้ แล้วเปลี่ยนรหัสผ่าน Admin

เว็บอยู่ที่ `https://<ชื่อเครื่องแม่>:8000` เช่น เครื่องแม่ชื่อ `AUCC-SERVER` จะใช้ `https://AUCC-SERVER:8000` ข้อมูลล็อกอินครั้งแรกอยู่ที่ `%ProgramData%\AUCC Server\admin-login.txt` หรือทางลัด **Admin login**

### 2. ติดตั้งเครื่องลูก (Client)

1. บนเครื่องแม่ เปิดทางลัด **Client installer** หรือไปที่ `%ProgramData%\AUCC Server\AUCCClientSetup.exe`
2. คัดลอกไฟล์นี้ไปเครื่องลูกแต่ละเครื่อง
3. Sign in ด้วยบัญชี Windows ที่จะใช้ Agent เปิดไฟล์แล้วกดติดตั้ง
4. Agent เริ่มทำงานหลังติดตั้ง เครื่องใหม่ได้รับอนุมัติอัตโนมัติและปรากฏบนหน้า Admin จากนั้นทดสอบล็อกอินหรือ Access Code

**การเชื่อมต่อ Client:** เครื่องแม่สร้าง `AUCCClientSetup.exe` ที่ฝัง URL เช่น `wss://AUCC-SERVER:8000/api/ws/agent`, ใบรับรองสาธารณะ (CA) และกุญแจลงทะเบียนไว้แล้ว จึงไม่ต้องกรอก IP/URL หรือแก้ config เอง Agent เริ่มอีกครั้งเมื่อบัญชี Windows ที่ติดตั้ง sign in

ชุด Client เป็นของ Server นั้นโดยเฉพาะและมีกุญแจเพิ่มสถานี แจกเฉพาะเครื่องที่อนุญาต ไม่เผยแพร่ไฟล์นี้สาธารณะ

### 3. ตรวจว่าพร้อมใช้งาน

- เปิดเว็บจากเครื่องลูกได้และไม่มีคำเตือน certificate หลังติดตั้งด้วยบัญชี Windows เดียวกัน
- หน้า Admin แสดงเครื่องลูก online และแต่ละเครื่องมีชื่อไม่ซ้ำ
- ทดลองจอง กรอก Access Code และสั่ง `LOGOUT` แล้วเครื่องกลับหน้าล็อก

## ดูแลและแก้ปัญหา

| เรื่อง | วิธีตรวจ/จัดการ |
|---|---|
| Client เชื่อมไม่ได้ | ตรวจเครือข่าย ชื่อเครื่องแม่ และพอร์ต 8000; ตัวติดตั้งไม่แก้ DNS/router หรือเครือข่ายที่แยก VLAN ให้ |
| Server ติดตั้งไม่สำเร็จ | ดู `%ProgramData%\AUCC Server\setup.log` และ `backend-go\server.err.log`; พอร์ต 8000/3308 ต้องไม่ถูกโปรแกรมอื่นใช้ |
| ติดตั้ง Server ซ้ำ | รักษาฐานข้อมูล บัญชีและ config เดิม; สำรองข้อมูลก่อนอัปเกรดเสมอ |
| ย้าย Client ไป Server อื่น | ถอน Agent เดิมก่อน แล้วติดตั้งชุด Client จาก Server ใหม่ |
| ถอน Server | หยุดระบบและลบ task/firewall rule แต่เก็บฐานข้อมูลและค่าลับไว้สำหรับกู้คืน |
| Agent ไม่เริ่มหลังเปิดเครื่อง | ต้อง sign in บัญชี Windows ที่ติดตั้ง Agent ก่อน |

ข้อมูล Server อยู่ที่ `%ProgramData%\AUCC Server` ส่วน config Client อยู่ที่ `%LOCALAPPDATA%\AUCC Agent\config.json` ฐานข้อมูลใช้พอร์ต 3308 เฉพาะภายในเครื่องแม่ ไม่ต้องเปิดพอร์ตนี้ให้เครื่องลูก

หน้าล็อก Agent เป็น overlay ใน Windows session เครื่องสาธารณะควรใช้บัญชี Windows สิทธิ์จำกัด ตัวติดตั้งยังไม่มีลายเซ็น Authenticode และยังต้องตรวจ GUI/UAC การรีบูต และเครื่องลูกจริงก่อนกระจายใช้งาน
