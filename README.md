# ระบบเข้าใช้งานคอมพิวเตอร์

ระบบสำหรับห้องคอมพิวเตอร์ ผู้ใช้จองและเข้าใช้เครื่องผ่านหน้าเว็บ ผู้ดูแลดูสถานะ ควบคุมเครื่อง และดูประวัติการใช้งานจากเครื่องแม่ได้

**รุ่นปัจจุบัน: 1.2.0** · [ดาวน์โหลดตัวติดตั้งเครื่องแม่](https://github.com/chaiyapatrx/Project/releases/download/v1.2.0/LabAccessServerSetup-1.2.0.exe) · [Release และ SHA-256](https://github.com/chaiyapatrx/Project/releases/tag/v1.2.0)

## แต่ละส่วนทำอะไร

| ส่วน | หน้าที่ | โฟลเดอร์ |
|---|---|---|
| หน้าเว็บ (React) | เข้าสู่ระบบ จองเครื่อง ดูสถานะและรายงานตามสิทธิ์ | `frontend` |
| Server (Go) | ตรวจสิทธิ์ จัดการการจอง/เวลาใช้งาน และส่งคำสั่งให้เครื่องลูก | `backend-go` |
| ฐานข้อมูล (MariaDB) | เก็บบัญชี สถานี การจอง การตั้งค่า และประวัติ; migration จัดโครงสร้างฐานข้อมูล | `migrations` |
| Agent บน Windows | เชื่อมเครื่องแม่ แสดงหน้าล็อก รับรหัสเข้าใช้ และรายงานสถานะเครื่อง | `client-go` |
| Updater | เปลี่ยนรุ่น Agent เมื่อผู้ดูแลปล่อยอัปเดต และคืนรุ่นเดิมหากรุ่นใหม่เปิดไม่ผ่าน | `client-go/updater` |
| ตัวติดตั้ง | เตรียม Server และสร้างชุด Client ที่มีค่าการเชื่อมต่อพร้อมใช้ | `installer`, `scripts` |

```text
หน้าเว็บ ── HTTPS / สถานะสด ── เครื่องแม่ ── ฐานข้อมูล
                                  │
                           WSS / คำสั่งเครื่อง
                                  │
                           Agent บนเครื่องลูก
```

**เครื่องแม่** เปิดเว็บและจัดการข้อมูลกลาง ส่วน **เครื่องลูก** ติดตั้ง Agent แล้วเชื่อมกลับมายังเครื่องแม่ ทุกเครื่องใช้ Server เดียวกัน

## วิธีใช้งาน

1. เครื่องลูกเชื่อมต่อและแสดงหน้าล็อก ผู้ดูแลเห็นสถานะบนเว็บ
2. ผู้ใช้จองเครื่องว่างบนเว็บ ได้ **Access Code 6 หลัก** แล้วกรอกที่เครื่องนั้นเพื่อเข้าใช้ การจองเริ่มทันที ไม่ใช่จองวันเวลาล่วงหน้า
3. ถ้าเครื่องว่างและไม่มีการจอง ผู้ใช้ล็อกอินด้วยบัญชีของระบบที่เครื่องได้โดยตรง (walk-in)
4. ระบบบันทึกประวัติและนับเวลา เมื่อหมดเวลา ยกเลิก หรือสั่ง `LOGOUT` จะจบการใช้งานและกลับหน้าล็อก หากขาดการเชื่อมต่อ Agent จะล็อกหน้าจอ

| สิทธิ์ | ใช้งานได้ |
|---|---|
| Admin | จัดการบัญชี/สถานี ตั้งค่าระบบ ควบคุมเครื่อง และอัปโหลดรุ่น Agent |
| Staff | ดูสถานี/การจอง/ประวัติ ควบคุมเครื่อง และปล่อยหรือพักรุ่น Agent ที่อัปโหลดแล้ว |
| Executive | ดูสถิติและรายงาน |
| Student | จอง ดู ยกเลิก และต่อเวลาการจองของตนตามเงื่อนไข |

## วิธีติดตั้ง (ไม่ต้องมีความรู้ไอที)

มีโปรแกรมติดตั้งแค่ 2 ไฟล์ กดถัดไปจนจบได้เลย ไม่ต้องพิมพ์อะไร

- **เครื่องแม่** คือเครื่องของผู้ดูแล มีเครื่องเดียว
- **เครื่องลูก** คือเครื่องที่ให้นักศึกษาใช้

ทุกเครื่องต้องเป็น Windows 10 หรือ 11 และต่อเน็ตวงเดียวกัน (LAN หรือ Wi-Fi เดียวกัน)

### ขั้นที่ 1: ติดตั้งเครื่องแม่ (ทำครั้งเดียว)

1. ดาวน์โหลด [LabAccessServerSetup-1.2.0.exe](https://github.com/chaiyapatrx/Project/releases/download/v1.2.0/LabAccessServerSetup-1.2.0.exe) มาไว้ที่เครื่องแม่
2. ดับเบิลคลิกไฟล์ ถ้า Windows ถามว่า "อนุญาตให้แอปนี้ทำการเปลี่ยนแปลงอุปกรณ์หรือไม่" กด **ใช่**
3. กด **Next** หรือ **Install** จนเสร็จ แล้วรอสักครู่
4. ตอนจบจะเปิดไฟล์ชื่อผู้ใช้กับรหัสผ่าน และเปิดเว็บให้เอง ใช้ชื่อกับรหัสนั้นเข้าสู่ระบบ และเก็บไฟล์นั้นเป็นความลับ

หลังติดตั้ง บนหน้าจอเครื่องแม่จะมีไอคอน 2 อัน:

- **ระบบเข้าใช้งานคอมพิวเตอร์** ใช้เปิดหน้าเว็บ
- **ตัวติดตั้งเครื่องลูก** ใช้หาไฟล์สำหรับลงเครื่องลูก

ระบบเปิดเองทุกครั้งที่เปิดเครื่องแม่ และสำรองข้อมูลให้เองวันละครั้ง ไม่ต้องกดอะไร

### ขั้นที่ 2: ติดตั้งเครื่องลูก (ทำทีละเครื่อง)

1. ที่เครื่องแม่ ดับเบิลคลิกไอคอน **ตัวติดตั้งเครื่องลูก** จะเห็นไฟล์ `LabAccessClientSetup.exe`
2. คัดลอกไฟล์นี้ใส่แฟลชไดรฟ์ หรือส่งผ่านโฟลเดอร์ที่แชร์ในวง LAN ไปไว้ที่เครื่องลูก
3. ที่เครื่องลูก เข้า Windows ด้วยบัญชีที่นักศึกษาจะใช้ แล้วดับเบิลคลิก `LabAccessClientSetup.exe`
4. กด **Next** หรือ **Install** จนเสร็จ เครื่องลูกจะหาเครื่องแม่เอง ไม่ต้องกรอกที่อยู่
5. เครื่องลูกจะขึ้นหน้าล็อก "ระบบเข้าใช้งานคอมพิวเตอร์" แปลว่าใช้ได้แล้ว

ตอนติดตั้งเครื่องลูก **ต้องเปิดเครื่องแม่ไว้**

### ถ้า Windows ขึ้นกรอบสีน้ำเงิน "Windows protected your PC"

กด **ข้อมูลเพิ่มเติม (More info)** แล้วกด **เรียกใช้ต่อ (Run anyway)** กรอบนี้ขึ้นเพราะโปรแกรมยังไม่มีลายเซ็นดิจิทัล ทำแบบนี้เฉพาะกับไฟล์ที่ได้จากผู้ดูแลระบบเท่านั้น

### ตรวจว่าใช้ได้

1. เปิดหน้าเว็บที่เครื่องแม่ ไปหน้าเครื่องคอมพิวเตอร์ ต้องเห็นเครื่องลูกขึ้นว่า online
2. ลองจองเครื่องบนเว็บ จะได้รหัส 6 หลัก
3. พิมพ์รหัสนั้นที่เครื่องลูก ถ้าเข้าใช้ได้ แปลว่าเรียบร้อย

### ถ้ามีปัญหา

| อาการ | วิธีแก้ |
|---|---|
| เครื่องลูกไม่ขึ้นในเว็บ | เช็กว่าเครื่องแม่เปิดอยู่และต่อเน็ตวงเดียวกัน แล้วรีสตาร์ตเครื่องลูก |
| ติดตั้งเครื่องแม่ไม่ผ่าน | รีสตาร์ตเครื่องแม่แล้วติดตั้งใหม่ ถ้ายังไม่ผ่าน ส่งไฟล์ `C:\ProgramData\LabAccess Server\setup.log` ให้ผู้พัฒนา |
| ลืมรหัสผ่าน admin ของครั้งแรก | ที่เครื่องแม่ เปิดเมนู Start แล้วพิมพ์ **Admin login** |
| เปิดเครื่องลูกแล้วไม่ขึ้นหน้าล็อก | เข้า Windows ด้วยบัญชีเดียวกับตอนติดตั้ง |
| ลงเครื่องลูกใหม่ (หรือลง Windows ใหม่) แล้วเครื่องไม่ขึ้น | ในหน้าเว็บ ลบเครื่องนั้นออก รอเครื่องขึ้นใน "Stations waiting for approval" แล้วกดอนุมัติ ประวัติการใช้งานเดิมยังอยู่ |
| จะย้ายเครื่องลูกไปใช้กับเครื่องแม่เครื่องใหม่ | ถอนการติดตั้ง "ระบบเข้าใช้งานคอมพิวเตอร์ (เครื่องลูก)" ที่ Settings > Apps ก่อน แล้วลงไฟล์จากเครื่องแม่เครื่องใหม่ |
| อยากสำรองข้อมูลเดี๋ยวนี้ | ที่เครื่องแม่ เปิดเมนู Start พิมพ์ **สำรองข้อมูลตอนนี้** ไฟล์สำรองดูได้จาก **เปิดโฟลเดอร์ไฟล์สำรอง** ควรคัดลอกเก็บไว้นอกเครื่องเป็นระยะ |

**ข้อควรระวัง**

- ไฟล์ `LabAccessClientSetup.exe` ใช้เพิ่มเครื่องเข้าระบบได้ อย่าแชร์ในที่สาธารณะ
- ควรให้เครื่องแม่ใช้ IP เดิมตลอด ให้คนที่ดูแลเราเตอร์ช่วยตั้งให้ถ้าทำได้
- ติดตั้งเครื่องแม่ซ้ำแล้วข้อมูลเดิมไม่หาย แต่ควรกด **สำรองข้อมูลตอนนี้** ก่อนเสมอ

### สำหรับผู้ดูแลเทคนิค

- ข้อมูล Server อยู่ที่ `%ProgramData%\LabAccess Server` ส่วน log อยู่ที่ `setup.log`, `backup.log` และ `backend-go\server.err.log`
- ไฟล์สำรองอยู่ที่ `%ProgramData%\LabAccess Server\backups` (`mariadb-dump` แบบ `--single-transaction` เก็บ 30 ไฟล์ล่าสุด) กู้คืนด้วย `mariadb\bin\mariadb.exe` ด้วยบัญชี root ใน `database-admin.txt` หลังหยุดระบบ ควรทดลองกู้คืนบนเครื่องทดสอบก่อนใช้จริง
- ใช้พอร์ต 8000 (HTTPS, firewall เปิดเฉพาะ LocalSubnet) และ 3308 (MariaDB, ใช้เฉพาะในเครื่องแม่) ทั้งสองพอร์ตต้องว่าง
- config ของ Agent อยู่ที่ `%LOCALAPPDATA%\LabAccess Agent\config.json`
- Client Setup ลองต่อด้วยชื่อเครื่องแม่ก่อน ถ้าไม่ได้จะลอง IP ของเครื่องแม่ที่บันทึกไว้ตอนติดตั้ง IP เหล่านี้อยู่ในใบรับรอง HTTPS ด้วย
- หน้าล็อกของ Agent เป็น overlay ใน Windows session ไม่ใช่ secure lock ของ OS ควรใช้บัญชี Windows สิทธิ์จำกัด
- ยังต้องทดสอบ GUI/UAC การรีบูต และเครื่องลูกจริงก่อนกระจายใช้งาน
